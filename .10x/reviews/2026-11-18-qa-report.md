## Bugs found and fixed during verification
1. **A11y:** icon-only Export button on phone had no accessible name → `aria-label="Ekspor laporan"`.
2. **Chart:** y-axis ticks 5,5 rb / 16,5 rb → `niceTicks` (0/10/20/30 rb).
3. **Chart:** single active hour produced a 2-bar chart → minimum 8-hour window.
4. **PDF:** numeric column headers left-aligned over right-aligned values → right-aligned.
5. **Perf:** CSV export constructed an `Intl.DateTimeFormat` per row (1 234 ms / 20k) → cached (207 ms).
