# Runbook — variants and add-ons (v0.13)

| Symptom | Cause | Action |
| --- | --- | --- |
| "Where did Varian go?" | Renamed: what used to be "Varian" (ice, sugar, size, topping) is now **Add-on** | Produk → tab Add-on. Nothing was lost. |
| Need Latte / Americano / Espresso under Kopi at different prices | That is a **variant** | Produk → open Kopi → "Punya varian" → add each with its price. |
| Tile says "Mulai Rp15.000" | The product has variants; that is the cheapest | Expected. |
| "Pilih varian" on the button, cannot add | No variant chosen | Tap a variant first. |
| A variant is greyed out with "Habis" | Marked sold out | Kasir → sold-out list → under the product, switch the variant back. Closing the day resets it. |
| Whole product shows Habis | The product itself, or every variant, is sold out | Same list. |
| Takeaway price of a variant equals its Dine In price | No Takeaway price was set for that variant | Produk → variant → "Harga Takeaway". It never falls back to the product's old takeaway price. |
| Add-on not offered for a product | The group is not attached | Produk → open product → section Add-on → tap the group. |
| Same add-on group needed with different options per variant | Not supported | Make two products, or one group covering all options. |
| Excel Item sheet: "Varian" column moved? | Old column is now headed "Add-on" (same place); the variant name is in a new last column "Varian" | Update spreadsheet formulas that read the header text. |
